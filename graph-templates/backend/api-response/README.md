# backend.api-response

**What.** `sendSuccess(res, data, message?, status?)` and `sendPaginated(res, items, meta, message?)` — the success-side counterpart to `backend.error-handler`'s error envelope. Not present in the reference app; added because every controller generated by `api.crud` needs one consistent shape to be predictable to a frontend/testing agent.

**When.** After `project.node-express`; before `backend.controller`/`api.crud`, which call these helpers instead of `res.json()` directly.

**Requires.** `project.node-express`.

**Produces.** `src/utils/apiResponse.ts` exporting `sendSuccess`, `sendPaginated`, `PaginationMeta`.

**Connects to.** Downstream: `backend.controller`, `api.crud` (both call `sendSuccess`/`sendPaginated` instead of ad hoc `res.json`).

**Test.** `npm test -- apiResponse` — asserts the JSON shape and default status/message.

**Security.** This helper does not filter fields — callers must exclude secrets (password hashes, token hashes) from `data` before calling it, same discipline the reference app already applies in `AuthenticationRepository.toPublicUser`.
