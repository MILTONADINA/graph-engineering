To add a field: insert one new column line into the existing `pgTable('{{input.tableName}}', { ... })` call in `schema.ts` (before the `createdAt` line), never regenerate the whole table block. Then run `npm run dbGenerate` to create the incremental migration. The repository class itself (`src/repository/<Entity>.ts`) does not need edits — its CRUD methods are field-agnostic (`Partial<New<Entity>>`).
