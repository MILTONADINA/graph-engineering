To widen/narrow the filter or sort allowlist: re-render only the `FILTERABLE_FIELDS`/`SORTABLE_FIELDS` object literals inside the existing `findMany` method with the new `filterableFields`/`sortableFields` — do not touch `create`/`findById`/`update`/`remove`, and do not re-invoke the four composed backend.* nodes (they have nothing to do with filtering). To add a field to the entity itself, use `backend.repository`'s own `modify` action directly, then re-run this node's step 5 only if the new field should also become filterable/sortable.
