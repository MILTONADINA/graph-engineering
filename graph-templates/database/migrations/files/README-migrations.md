# Migrations

Everything in this folder is generated by `npm run dbGenerate` (drizzle-kit, reading `src/config/schema.ts`) and applied by `npm run dbMigrate`. Both scripts are added to `package.json` by `database.neon-postgres.connection`.

- Never hand-edit a `.sql` file here — the `meta/` snapshots next to it must stay in lockstep, or `dbGenerate`'s drift detection breaks.
- Every `backend.repository` node run should be followed by `npm run dbGenerate` (it appends to `schema.ts`, this is what turns that into a migration).
- Run `npm run dbMigrate` manually or via a reviewed CI step — never automatically from an agent's own generate loop (see `database.migrations`'s `template.yaml` security notes).
